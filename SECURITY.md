# Security

- API keys, PC token aur chat sirf user ke phone me (SharedPreferences) rehte hain. Repo me koi key nahi hoti.
- Agent screen/web page/file ke andar likhe instructions ko hukm nahi maanta; sirf user ka goal.
- Risky kaam (payment, order, trade submit, delete, shell) par user ki "haan" zaroori hai.
- Security audit sirf Settings me likhi user ki apni sites par chalta hai.
- PC link LAN par plain HTTP + token hai; sirf bharose ke WiFi par chalao.

Bug mila? GitHub Issues me private detail ke bina likho ya maintainer ko seedha batao.
